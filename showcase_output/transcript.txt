==============================================================================
  4. THE CLOSED LOOP: the agent earns autonomy, then loses it
==============================================================================
The agent starts at T0 (observe only). Every request: trace -> model -> policy ->
gate -> decision; then the TRUE outcome is fed back and the trust tier may move.
Promotion needs a Wilson lower bound over fresh evidence; a missed real bug demotes.
